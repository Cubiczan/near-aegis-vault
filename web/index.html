How it works

The AI agent's account has no full-access key. Its only key is a NEAR function-call access key that can call one method, request_spend, on this vault. The vault checks every request on-chain: duplicate invoice → vendor allowlist → hard cap → velocity → approval threshold / daily cap. Blocked attempts are recorded too, so you get an audit trail of what a hijacked or prompt-injected agent tried to do.
